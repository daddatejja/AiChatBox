Learn how to integrate AiChatBox into your own projects and leverage custom tools.

Quick Start

1

Embed the Widget

Add the following script and tag to your HTML page. Replace YOUR_API_KEY with a key from your project settings.

<!-- Include the widget script --> <script src="https://your-domain.com/ai-chatbox.js"></script> <!-- Add the component --> <ai-chatbox api-url="https://your-domain.com" api-key="YOUR_API_KEY"> </ai-chatbox>

Tool Execution Support

AiChatBox supports two ways to execute custom logic through the AI.

Option A: JavaScript Callbacks (Frontend)

Perfect for interacting with the current page UI or local data.

const assistant = document.querySelector('ai-chatbox'); // Register a tool handler assistant.registerTool('get_user_info', async (args) => { return { name: "John Doe", membership: "Premium" }; });

Option B: Webhooks (Backend)

Securely execute logic on your own server. Configure your Webhook URL in the project dashboard.

When the AI calls a tool, your server receives a POST request:

// Node.js / Express Example app.post('/webhook', (req, res) => { const { tool, arguments: args } = req.body; if (tool === 'check_inventory') { const stock = db.query("SELECT qty FROM stock WHERE id = ?", [args.id]); return res.json({ available: stock > 0 }); } res.status(404).send('Tool not found'); });

Best Practices

  • Use descriptive names for your custom tools (e.g. search_database instead of run).
  • Keep your System Prompt concise but specific about the tools available.
  • Always validate the X-Hub-Signature header on your webhooks if using a secret.
